# applied-data-science
Repository for project in TDT4259 Applied Data Science 

## Project objectives
The objective of the project was to go through the full life cycle of a data science project using the [CRISP-DM](https://en.wikipedia.org/wiki/Cross-industry_standard_process_for_data_mining) model. 

## Deliverables
The project group developed a machine learning model that suggests if Airbnb listings are appropriately priced. 

The main deliverable was the report and the conducted exloratory data analysis and modelling, all of which can be found in the repo.
